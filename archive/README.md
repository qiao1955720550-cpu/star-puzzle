# 星星网页 — 最终版存档

**存档日期**：2026-05-15

## 项目概述
纯网页交互式寻宝游戏。像素风女孩房间中探索物品、触发7段祖孙回忆故事、收集6块拼图碎片，拼出合照。另有DIY模式自由拖拽家具。

## 文件说明

| 文件 | 说明 |
|------|------|
| index.html | 主页面，包含所有视图结构 |
| style.css | 全局样式（CSS变量、主页、房间、日记本、拼图、DIY） |
| game.js | 游戏逻辑（状态管理、交互、拖拽、存档） |

## 功能清单

### 主页
- 自定义背景图（images/42.jpg）
- 标题图片淡入动画（images/d.png）
- 两个入口按钮：开始寻宝 / DIY房间

### 寻宝模式（像素风房间）
- 11个可交互物品，悬停高亮
- 7段故事：浮动日记本 + 打字机逐字效果
- 6块碎片收集
- 顶部状态栏 + 返回主页 + 暂停/还原气泡按钮

### 拼图系统
- 长方形碎片（210×130，2×3=6块，总420×390）
- 拖拽自动吸附
- 用户可替换 images/puzzle/full-photo.png
- 完成后碎片消失，完整大图浮现 + 庆祝彩星

### DIY房间
- 6件扁平彩色抽象风家具，平铺不重叠
- 自由拖拽布置
- 还原默认按钮
