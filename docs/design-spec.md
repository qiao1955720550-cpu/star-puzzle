# 设计规范

## 整体基调
童趣、梦幻、甜美，彩铅/手绘质感。浅蓝+粉色为主，房间背景融入星星元素。

## 配色方案

### CSS 变量定义
```css
:root {
  --pink-light: #FFD1DC;      /* 浅粉 */
  --pink: #FFB6C1;            /* 粉色 */
  --pink-deep: #F8A5B5;       /* 深粉 */
  --blue-light: #C5E8F0;      /* 浅蓝 */
  --blue: #87CEEB;            /* 天蓝 */
  --blue-deep: #6BB5CC;       /* 深蓝 */
  --lavender: #E8D5F0;        /* 淡紫 */
  --cream: #FFF8F0;           /* 米白 */
  --star: #FFE9A0;            /* 星星金色 */
  --text: #5D4E5F;            /* 文字灰紫 */
  --shadow: rgba(160, 140, 160, 0.2); /* 柔阴影 */
}
```

## 三种美术风格

### ① 像素风（寻宝房间）
- 用 CSS box-shadow 和 grid 模拟像素点
- 小动画：窗帘微动、灯光闪烁、星星飘浮、粒子效果
- 物品边缘清晰、色彩块状
- 像素格子大小：4px × 4px

### ② 扁平手绘装饰风（故事弹窗/日记本）
- 柔和线条、圆角
- 纸质纹理感背景
- 手写体/圆体字体
- 日记本折痕、便签纸阴影

### ③ 扁平彩色抽象童趣风（DIY家具）
- 色彩明快、饱和度高
- 几何抽象形状
- 大色块、明显圆角
- 家具用 color-block 风格

## 字体
- 标题：圆体/卡通体（系统默认 fallback: "KaiTi", "STKaiti"）
- 正文：手写体风格（系统默认 fallback: "KaiTi", "STKaiti"）
- 英文/数字：圆体

## 动效规范
- 按钮 hover：轻微放大(1.05x) + 阴影加深
- 按钮 click：缩小回弹(0.95x → 1.02x → 1x)
- 弹窗出现：从物品位置缩放浮出
- 弹窗消失：淡出缩小
- 打字机：60ms/字，标点停顿100ms
- 星星闪烁：2-4s 循环，随机延迟
- 过渡时长：0.3s ~ 0.5s

## 布局
- 桌面端优先，固定 1200×800 或自适应
- 房间场景占主体区域
- 弹窗居中覆盖
- 状态栏固定在顶部
