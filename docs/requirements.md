# 项目需求文档

## 项目名称
星星网页 — 交互式寻宝游戏

## 概述
纯网页交互式寻宝游戏。像素风小女孩房间中，玩家探索物品触发7段祖孙回忆故事，收集6块拼图碎片，最终拼出小女孩与姥姥的合照。同时提供DIY模式自由拖拽家具。

## 核心玩法

### 寻宝模式
- 像素风房间场景，11个可交互物品
- 悬停高亮/微动提示可点击
- 点击物品触发：故事（7段）或碎片（6块）或两者皆有（2处重叠）
- 顶部状态栏：故事 X/7 | 碎片 X/6

### 故事系统
- 点击物品后浮动弹出日记本/便签
- 扁平手绘风插画 + 文字
- 打字机逐字输出效果
- 一两句话，简短温暖

### 拼图系统
- 收集6块碎片后可拼图
- 拖拽碎片到正确位置，自动吸附
- 完成展示合照 + 庆祝动画

### DIY模式
- 扁平彩色抽象风家具
- 自由拖拽布置
- 不保存，还原默认按钮

## 7段故事

| # | 物品 | 内容 |
|---|------|------|
| 1 | 水杯 | 姥姥总在杯子里泡好温水等我放学。杯子上还贴着她特意为我选的小兔贴纸。 |
| 2 | 窗台盆栽 | 姥姥说花开了就带我去公园。她每天认真浇水，可花一直没开——后来我才知道，她种的是不会开花的绿萝。 |
| 3 | 故事书 | 姥姥的普通话不标准，总把"小王子"念成"小丸子"。但那些夜晚，是我听过最好的故事。 |
| 4 | 布偶兔子 | 姥姥缝的兔子一只耳朵长、一只耳朵短。她说是因为线不够了——但我知道，她是想让我的兔子和别人的都不一样。 |
| 5 | 台灯 | 无数个夜晚，姥姥坐在这盏台灯下，陪我一笔一画地写字。灯光昏黄，却是我记忆里最暖的颜色。 |
| 6 | 一张涂鸦画 | 桌上有一张我小时候画的蜡笔画，歪歪扭扭的小人和花朵。姥姥一直留着，折痕都发白了也没舍得扔。 |
| 7 | 鱼缸里的金鱼 | 姥姥养了两条小金鱼，一条叫小红，一条叫小白。她每天喂食的时候都跟它们说话："你们要替我陪囡囡啊。" |

## 11个物品分类

| 类型 | 物品 |
|------|------|
| 故事+碎片(2) | 布偶兔子、台灯 |
| 纯故事(5) | 水杯、窗台盆栽、故事书、一张涂鸦画、鱼缸里的金鱼 |
| 纯碎片(4) | 枕头、闹钟、画框、音乐盒 |
