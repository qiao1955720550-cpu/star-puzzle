# 项目需求

## 概述
开发一个"手风琴经折页手账本"交互组件，用户可点击展开、鼠标翻页、上传图片。

## 功能需求

### 书本外观
- 封面：合着时可见，手绘温暖风格
- 内页：经折页式折叠，每两页一个对开图
- 背景：浅米色(#FBF7F0) + 浅棕色网格或波点纹理

### 交互行为
1. 初始显示合着的书本（仅封面可见）
2. 点击封面 → 经折页在屏幕上横向展开
3. 展开后鼠标交互翻页：
   - 鼠标移到右侧区域 → 自动缓缓向前翻页
   - 鼠标移到左侧区域 → 自动缓缓向后翻页
   - 鼠标在中间区域 → 停止翻页
   - 鼠标离边缘越近翻页越快
4. 翻到最后一页 → 显示"翻到反面"按钮
5. 点击翻面 → 切换为反面新图片，重复翻页交互

### 图片管理
- 封面支持点击上传替换
- 每个对开页支持点击上传替换
- 未上传时使用纯色占位图

### 数据规格
- 共16页 = 正面8个对开页 + 反面8个对开页 = 16张图
- 封面额外1张图
- 总计17个可编辑图片位

## 非功能需求
- 纯前端实现，双击 index.html 即可运行
- 桌面端优先，适配 4:3 画幅
- 支持主流浏览器（Chrome, Edge, Firefox）
